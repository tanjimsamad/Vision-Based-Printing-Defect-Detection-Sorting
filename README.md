# Vision-Based Printing Defect Detection and Sorting System
Vision-Based Printing Defect Detection and Sorting System

Deep Learning: Leveraged YOLOv11n for high-accuracy detection of defects like "Miss-Print" and misalignments, optimized for low-latency edge deployment.

Computer Vision: Utilized OpenCV for live frame processing, dynamic annotation, and defect visualization.

Hardware Automation: Engineered a real-time sorting mechanism by interfacing Arduino with Python via pyfirmata2 for immediate servo actuation.

User Interface: Designed a Tkinter-based GUI for live feed monitoring, system status updates, and manual override controls.
